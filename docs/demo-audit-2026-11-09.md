# CollabMuse 答辩演示检查

本次在本机独立测试数据上操作，不涉及用户现有作品。以下是本次观察，不代表完整验收。

## 实际操作结果

- 首页和演示房间可以打开；空演示房间明确提示示例片段不是音频，播放按钮禁用。
- 在音乐助手中使用内置规则编曲生成 30 秒音频，界面显示试听控件，可添加到工作台。
- 添加后出现第五条音轨和实际音频片段；点击播放、暂停，时间从 0 秒前进到约 12 秒。未人工监听声音，也未验证音质或导出音频。
- 新建时间点留言后，界面提示保存并同步；活动页出现对应记录。
- 保存名为 Demo version 的版本，历史列表显示该版本；未测试版本恢复。
- 刷新页面、等待连接完成后，生成的音轨、片段和新留言仍在。未测试服务器重启、跨设备或意外断电恢复。

## 本次发现的问题和缺口

1. **演示素材容易误解**：初始时间线上的多个波形是没有音频的占位符，必须先生成或上传素材才能播放；虽然已有提示，但首次演示仍需要解释。
2. **音乐生成能力有限**：当前可用的是规则编曲器，界面明确说明不是 AI 音乐模型；提示词理解范围有限。真实外部 AI 服务、价格和音质没有在本次测试中验证。
3. **中英文混用**：中文界面仍出现 Music Generator、Generate music、时间线和音轨等英文，切换语言后部分内容未本地化。
4. **加载状态容易造成误解**：刷新后先短暂出现默认空时间线及连接中状态，随后才恢复已有作品；大型项目或慢网络下的表现未测。
5. **作品可靠性和跨设备协作尚未完成验收**：本次只测试本机刷新，没有测试服务器重启、真正的云存储、不同设备/账号、断线重连、并发冲突、权限变更或对方试听上传音频。
6. **音频闭环未完整验收**：没有人工试听生成结果或导出的混音，也没有本次实测录音、导入、剪切、音量、静音、循环和多个音轨同步的实际声音。
7. **合作反馈未完整验收**：本次只测试添加留言与活动记录；关联具体音频片段、回复、解决状态及版本 A/B 试听未在本次操作中验证。
8. **答辩录像未产出**：整屏录制会可能包含其他私人内容，被系统拦截；只录网站页面的独立浏览器启动也因审批服务错误未能运行。不能将未录制的素材当作演示视频。

## 建议的演示顺序

首页进入演示房间 → 解释示例片段 → Copilot 生成规则伴奏 → 加入工作台 → 播放 → 添加时间点留言 → 查看活动 → 保存版本。应在有声音输出的设备上事先试听，并明确说明本机原型和规则编曲的限制。
